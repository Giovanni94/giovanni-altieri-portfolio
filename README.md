# giovanni-altieri-portfolio

Sito CV di Giovanni Altieri, sviluppato con Angular e TypeScript.

## Sviluppo

```
npm install
npm start
```

Apri http://localhost:4200.

## Contenuti

I testi del CV sono in `public/cv.it.json` e `public/cv.en.json`.
I testi dell'interfaccia (menu, titoli delle sezioni…) sono in `src/app/i18n/ui.ts`.

## Build

```
npm run build
```

Il sito pronto da pubblicare è in `dist/frontend/browser`.
